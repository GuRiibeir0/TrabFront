# 🌐 TECHNOVA - Site do Evento

Este repositório contém o código-fonte do site do evento **TECHNOVA**, um dos maiores encontros de tecnologia e inovação do Brasil. Desenvolvido utilizando o framework Materialize CSS, o site apresenta informações sobre o evento, programação, palestrantes e um formulário de contato.

## 📁 Estrutura de Arquivos

- `index.html` – Página inicial com boas-vindas e chamada para ver a programação.
- `programacao.html` – Cronograma detalhado das atividades e palestras.
- `palestrantes.html` – Lista de palestrantes confirmados com mini bio.
- `contato.html` – Formulário de contato para dúvidas ou sugestões.

## 🛠️ Tecnologias Utilizadas
- **HTML**
- **CSS**
- **[Materialize CSS]** – Framework responsivo baseado no Material Design.
- **Google Fonts & Material Icons**

## 🎯 Funcionalidades

- Design responsivo para desktop.
- Navegação entre páginas usando um menu superior consistente.
- Apresentação visual clara da programação.
- Formulário funcional (estrutura HTML pronta para integração com back-end).
